# Security Policy · Güvenlik Politikası

## Reporting a vulnerability

Please do **not** open a public issue for security problems. Email **sismikapplication@gmail.com** with the subject `SECURITY`, a description of the issue and steps to reproduce. You will receive a reply within 72 hours. Please allow a reasonable time for a fix before you disclose the issue publicly.

In scope: the iOS app, the backend in `functions/`, and the Open Data API pipeline in `api/` and `.github/workflows/`.

## Güvenlik açığı bildirme

Güvenlik sorunları için lütfen herkese açık issue **açmayın**. Konu satırına `SECURITY` yazarak **sismikapplication@gmail.com** adresine sorunun açıklamasını ve yeniden üretme adımlarını gönderin. 72 saat içinde yanıt verilir. Sorunu kamuya açıklamadan önce düzeltme için makul bir süre tanımanızı rica ederiz.

Kapsam: iOS uygulaması, `functions/` altındaki sunucu ve `api/` ile `.github/workflows/` altındaki Açık Veri API'si hattı.
