Sismik Open Data API

Free, read-only earthquake feeds merged from nine seismological agencies — AFAD, Kandilli, EMSC, USGS, NOA, GeoNet, BMKG, JMA and CENC. No API key, no sign-up, CORS enabled.

Dokuz sismoloji ajansının (AFAD, Kandilli, EMSC, USGS, NOA, GeoNet, BMKG, JMA, CENC) verisini birleştiren ücretsiz, salt okunur deprem akışları. API anahtarı yok, kayıt yok, CORS açık.

Example

Örnek

const res = await fetch('https://kayaonur607.github.io/sismik/v1/earthquakes/turkiye.json');
const { generatedAt, earthquakes } = await res.json();
for (const q of earthquakes.filter(q => q.magnitude >= 3)) {
  console.log(q.time, q.source, `M${q.magnitude}`, q.place, `${q.depthKm} km`);
}

Record format

Kayıt biçimi

{
  "id": "afad-731155",
  "source": "AFAD",
  "magnitude": 1.3,
  "magnitudeType": "ML",
  "depthKm": 7,
  "latitude": 38.0745,
  "longitude": 38.3723,
  "time": "2026-10-11T09:20:15.000Z",
  "updatedAt": null,
  "place": "Çelikhan (Adıyaman)",
  "district": "Çelikhan",
  "province": "Adıyaman",
  "country": "Türkiye",
  "tsunami": false,
  "status": null,
  "url": "https://deprem.afad.gov.tr/apiv2/event/filter?eventid=731155"
}

The same physical earthquake can appear once per agency (for example AFAD and EMSC). Each record keeps its agency in source; we never alter agency values. Fields may be null when the agency does not publish them. New fields may be added within v1; existing fields will not change meaning.

Aynı fiziksel deprem her ajans için ayrı bir kayıt olarak görünebilir (ör. AFAD ve EMSC). Her kayıt ajansını source alanında taşır; ajans değerleri değiştirilmez. Ajans yayımlamıyorsa alanlar null olabilir. v1 içinde yeni alanlar eklenebilir; mevcut alanların anlamı değişmez.

Fair use

Adil kullanım

Files are static and served from GitHub's CDN — polling every minute is fine; there is no benefit to polling faster than the 10-minute refresh. Please cite the originating agency and Sismik, and respect each agency's own terms. This feed is informational: do not use it for early warning or life-safety decisions; follow AFAD and your local authorities.
Dosyalar statiktir ve GitHub'ın CDN'inden sunulur; dakikada bir sorgulamak sorun değildir, ancak 10 dakikalık yenilemeden sık sorgulamanın faydası yoktur. Lütfen kaynak ajansı ve Sismik'i belirtin, her ajansın kendi kullanım koşullarına uyun. Bu akış bilgilendirme amaçlıdır; erken uyarı ya da can güvenliği kararları için kullanmayın, AFAD'ı ve yerel yetkilileri takip edin.
